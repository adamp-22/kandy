# AI and Visualization Lab (WS26)

Group project for the AI and Visualization Lab at JKU (Visual Data Science Lab), winter semester 2026.

The assignment has two parts:

- **VIS4AI**: use visualization to explain an AI model and diagnose its failure modes.
  - Phase I: how does the model behave? (black box: inputs vs. outputs)
  - Phase II: what did the model learn? (internal representations)
- **AI4VIS**: explore how generative AI supports and influences the visualization design and analysis process.
